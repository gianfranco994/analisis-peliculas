# analisis-peliculas
# Análisis de mis películas y series favoritas

¡Hola! Este es un proyecto simple donde analicé mis películas y series favoritas usando Google Sheets y Python.

## Objetivo
El objetivo era crear un dataset personalizado y responder preguntas como:
- ¿Cuál es el género más común?
- ¿Cuál es la duración promedio?
- ¿Qué plataforma uso más?

## Herramientas usadas
- Google Sheets para crear el dataset.
- Python (con pandas y matplotlib) para el análisis y gráficos.

## Resultados
1. El género más común en mi lista es **Drama**.
2. La duración promedio de mis series es **43 minutos**.
3. La plataforma que más uso es **Netflix**.
